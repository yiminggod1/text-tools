Contact

We welcome reports that help improve the tools, documentation and user experience.

What to include in a bug report

Please describe the tool, the steps that caused the problem, the expected result, the actual result, and the browser/device when relevant. Do not include passwords or other sensitive information in a public issue.

Feedback and feature requests

Feature ideas are especially useful when they include the problem you are trying to solve and an example of the desired workflow.

Support channel

Use the project's public GitHub issue tracker for technical reports and requests. The repository owner can provide the appropriate contact channel there.
